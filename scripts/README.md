# Scripts

Utility scripts for otoyin development.

## Available

- `build-server.sh` — Build the otoyin-server binary via `backend/build_binary.py` and stage it into `tauri/src-tauri/binaries/otoyin-server` (runs on Linux/macOS/Git-Bash-on-Windows)
- `setup-dev.js` — Create placeholder sidecar binaries for local development
- `test_download_progress.py` — Test download progress reporting
