Anti-AI-slop compliance

  • ✓ No purple-pink gradient — flat rose accent, one place at a time (60-30-10)
  • ✓ No glassmorphism — every surface solid; blur reserved for nothing
  • ✓ No floating pills/toolbars — context UI anchored; toasts are transient confirmations only
  • ✓ No Lucide — heroicons-only (project invariant), consistent stroke weight
  • ✓ Button hierarchy (one primary), press feedback, keyboard focus rings
  • ✓ Empty + error + loading + success states designed, not defaulted
  • ✓ Labels not placeholders; validation on blur; translation headroom in labels
  • ✓ 4-role type scale; 4/8/12 radius; 4px spacing scale; motion <300ms, reduced-motion honored
