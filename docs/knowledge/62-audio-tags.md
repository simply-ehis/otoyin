# 62 — Audio Tags (Universal TTS Expressiveness)

PURPOSE: Bracketed tags ([pause], [laughs shy], [sigh]) parsed from TTS text, non-speech sounds loaded from real human sample library, text sent to TTS clean, then spliced together — works on any engine.
OWNS: backend/services/audio_tags.py, backend/services/audio_sample_library.py, backend/routes/audio.py (/audio/apply-tags, /audio/tags, /audio/tag-preview, /audio/sample-manifest), app/src/features/settings/GenerationPage.tsx (audio_tags toggle)
READ-WHEN: Adding new tag types, modifying sound playback, or changing how tags interact with TTS engines.
KEY-FILES: backend/services/audio_tags.py, backend/services/audio_sample_library.py, backend/scripts/curate_vocal_samples.py, backend/scripts/generate_starter_samples.py, backend/routes/audio.py, app/src/lib/api/clientStoriesA.ts (applyAudioTags, listAudioTags, previewAudioTag, getSampleManifest)
INVARIANTS: Tags are stripped before TTS for engines without native support. Engines with native tags (Chatterbox, ChatTTS, Zonos, Step-Audio-EditX, Orpheus) get tags rewritten to their native format and passed through. Sample library loaded from data/vocal_samples/<tag>/<variant>/*.wav. DSP used as fallback for pauses, speech modifiers, and missing classes.
GOTCHAS: tts_fn must be async. scipy.signal used for resampling — import at call time to avoid startup cost. Starter samples are synthetic; replace with real human recordings via curate_vocal_samples.py.

## Architecture

```
Input: "Hello [pause] I'm so [laughs shy] happy"
  ↓
1. PARSE: split into segments at tag boundaries
   → [{text: "Hello"}, {tag: "pause"}, {text: "I'm so"}, {tag: "laughs", modifiers: ["shy"]}, {text: "happy"}]
  ↓
2. GENERATE: TTS each text segment separately (tags stripped)
   → [speech_a, speech_b, speech_c]
  ↓
3. LOAD/SYNTHESIZE: load real human sample (or DSP fallback for pauses)
   → [pause_dsp, laugh_sample]
  ↓
4. MODIFY: apply modifier effects (pitch/time stretch for shy, quickly, etc.)
  ↓
5. SPLICE: interleave speech + sounds with crossfade
   → [Hello][pause][I'm so][laugh_shy][happy]
  ↓
6. CONCATENATE → final audio
```

## Sample Library

Real human vocal recordings stored in `data/vocal_samples/<tag>/<variant>/*.wav`:

| Tag | Variants | Source |
|-----|----------|--------|
| laughs, chuckles, giggles | normal, soft, loud | TTS-AGI/vocal-bursts (Laughter) |
| sigh | normal, soft, loud | TTS-AGI/vocal-bursts (Sigh) |
| cough | normal, soft, loud | TTS-AGI/vocal-bursts (Cough) |
| yawn | normal, soft, loud | TTS-AGI/vocal-bursts (Yawn) |
| gasp | normal, soft, loud | TTS-AGI/vocal-bursts (Sniff) |
| breath, breaths | normal, soft, loud | TTS-AGI/vocal-bursts (Breath) |
| tsk | normal, soft, loud | TTS-AGI/vocal-bursts (Tongue Clicking) |
| hmmm, umm, uhh, gulps | — | DSP fallback (no suitable dataset class) |
| pause, short pause, long pause | — | DSP (silence) |
| whisper, shout | — | Speech modifiers (no audio) |

### Replacing Starter Samples

Starter samples are synthetic (generated by `generate_starter_samples.py`). To replace with real human recordings:

```bash
python -m backend.scripts.curate_vocal_samples --per-tag 10
```

Downloads from TTS-AGI/vocal-bursts (open dataset), scores quality, saves best samples as 24kHz mono WAV.

## Supported Tags

| Category | Tags | Default Duration |
|----------|------|-----------------|
| Pauses | `[pause]`, `[short pause]`, `[long pause]` | 500ms, 250ms, 1000ms |
| Laughter | `[laughs]`, `[chuckles]`, `[giggles]` | 900ms, 700ms, 600ms |
| Emotions | `[sigh]`, `[gasp]`, `[gulps]` | 800ms, 400ms, 300ms |
| Fillers | `[hmmm]`, `[umm]`, `[uhh]` | 600ms, 400ms, 350ms |
| Breaths | `[breath]`, `[breaths]` | 350ms, 450ms |
| Other | `[cough]`, `[yawn]`, `[tsk]` | 350ms, 1200ms, 150ms |

## Modifiers

Apply to any tag: `[tag modifier1 modifier2]`

| Modifier | Effect |
|----------|--------|
| `shy` | quieter, shorter, slight pitch rise |
| `softly` | lower intensity |
| `loudly` | higher intensity |
| `quickly` | 70% duration |
| `slowly` | 130% duration |
| `nervously` | higher intensity, shorter, pitch rise |
| `thoughtfully` | longer, slight pitch drop |
| `deep` | louder, longer, pitch drop |

## API

```
POST /audio/apply-tags
  body: { text, engine?, voice?, language?, sample_rate?, crossfade_ms? }
  returns: { output_path, filename, duration_s, sample_rate, tags_found }

GET /audio/tags
  returns: { [tag_name]: { base_duration_ms, variance_ms, modifiers[], has_samples, sample_count, variants } }

GET /audio/sample-manifest
  returns: { [tag_name]: { has_samples, count, variants, is_dsp, laion_classes } }
```

## Native Tag Routing

Engines with native paralinguistic tag support get tags rewritten to their format and passed through — no sample loading, no DSP synthesis, no splitting, no crossfade:

| Engine | Native Tags | Format |
|--------|------------|--------|
| Chatterbox Turbo | `[laugh]`, `[chuckle]`, `[cough]` | Bracket |
| ChatTTS | `[laugh]`, `[cough]`, `[uh]`, `[um]`, `[noise]`, `[applause]`, `[laughter]` | Bracket |
| Zonos | `[angry]`, `[happy]`, `[sad]`, `[fearful]`, `[surprised]`, `[whisper]`, `[shout]`, `[laugh]`, `[cry]`, `[excited]` | Bracket |
| Step-Audio-EditX | `[Breathing]`, `[Laughter]`, `[Uhm]`, `[Cough]`, `[Sigh]`, `[Angry]`, `[Happy]`, `[Sad]`, `[Surprised]`, `[Whisper]` | Bracket |
| Orpheus | `<laugh>`, `<sigh>`, `<cough>`, `<sniffle>`, `<groan>`, `<yawn>`, `<gasp>` | Angle bracket |

Tags not in the engine's vocabulary are silently stripped. Tags with no native equivalent fall back to sample library or DSP.
