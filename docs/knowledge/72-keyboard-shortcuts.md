# Keyboard Shortcuts

> **PURPOSE** — Complete reference for all keyboard shortcuts in otoyin.
> **OWNS** — Keyboard interaction across all tabs.
> **READ-WHEN** — Building new UI features, or when a user asks about shortcuts.

## Global shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | Open command palette / search |
| `Ctrl+Z` | Undo last action |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+S` | Save current work (autosave is also active) |
| `Escape` | Close current dialog/overlay |
| `?` | Toggle help overlay |

## Audio Studio

| Shortcut | Action |
|----------|--------|
| `Space` | Play / Pause |
| `Enter` | Stop playback |
| `Delete` / `Backspace` | Delete selected clip |
| `Ctrl+D` | Duplicate selected clip |
| `Ctrl+S` | Split selected clip at playhead |
| `Ctrl+A` | Select all clips |
| `Escape` | Deselect clip |
| `+` / `=` | Zoom in |
| `-` | Zoom out |
| `0` | Fit timeline to view |
| `Home` | Jump to start |
| `End` | Jump to end |
| `M` | Toggle mute on selected track |
| `S` | Toggle solo on selected track |

## Story Editor

| Shortcut | Action |
|----------|--------|
| `Space` | Play / Pause story |
| `Enter` | Stop playback |
| `Delete` / `Backspace` | Delete selected clip |
| `Ctrl+D` | Duplicate selected clip |
| `Ctrl+S` | Split selected clip at playhead |
| `Escape` | Deselect clip |

## Generate tab

| Shortcut | Action |
|----------|--------|
| `Ctrl+Enter` | Generate speech (submit form) |
| `Escape` | Cancel generation |

## Captures tab

| Shortcut | Action |
|----------|--------|
| `Space` | Start/stop recording (when capture panel is focused) |
| `Escape` | Cancel recording |

## Assistant panel

| Shortcut | Action |
|----------|--------|
| `Ctrl+Enter` | Send message |
| `Shift+Enter` | New line in input |
| `Escape` | Close assistant panel |
| `Tab` | Switch between assistant tabs |

## Navigation

| Shortcut | Action |
|----------|--------|
| `1`-`9` | Jump to tab (when no input is focused) |
| `G` | Go to Generate tab |
| `V` | Go to Voices tab |
| `C` | Go to Captures tab |
| `A` | Go to Audio Studio |
| `S` | Go to Stories tab |
| `W` | Go to Workspace |

## Notes

- Shortcuts are disabled when an input field is focused (except `Ctrl+Enter` and `Escape`)
- Some shortcuts are context-dependent (e.g., split only works when a clip is selected)
- The `?` shortcut shows an interactive overlay with all available shortcuts for the current view
