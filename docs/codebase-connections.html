Findings

Nav contrast — now WCAG AA in all 7 themes

Only the active nav link failed (accent on accent-muted: 3.40 / 3.26 / 3.65). Inactive links already passed. Introduced --color-accent-ink — same hue and saturation as the accent, only lightness moves. Measured after: 4.51 / 4.51 / 5.36 / 12.96 / 4.83 / 5.94. Rejected two alternatives: crushing the tint to 11% (kills coastal-light) and retuning the brand accent itself.

Duplicated health poller — fixed

useBootReadiness polled /health/ready every 1.5s while BackendStatusBanner ran an independent query on the same URL — measured 18 requests per 20s. One ref-counted poller now serves both: 18 → 9. The regression test fails at 19 polls if the shared poller is removed.

Stale vite.config.js shadowed the maintained config

An untracked transpiled copy sat beside vite.config.ts. Vite resolves .js first, so every edit to the maintained config was silently ignored — which is why an earlier chunking fix produced a byte-identical bundle. Deleted; app/ and tauri/ configs now agree.

388 KB eager chunk removed

manualChunks on app-code directories hoisted whole route trees into one preloaded chunk. Every chunk in the app — down to 1 KB icon chunks — statically imported it. Removed; Rollup now splits per import() boundary. Startup bytes are ~flat (746 → 771 KB) because the code redistributed into correctly-attributed vendor chunks — the win is correct lazy boundaries, not saved bytes. Build time 2m40s → 41s.

Icon barrel imports are a dev-only cost

@heroicons/react shows ~730 KB in Vite dev, but the package is sideEffects:false and Rollup tree-shakes it: production startup contains zero heroicons bytes. Deep-importing 325 modules would be churn against a phantom.

components/ → features/ migration unfinished

0 modules exist in both trees and 0 component directories have no live importer — form one unreachable cluster: the router now resolves through @/features/workspace, so every remaining reference to them comes either from the unused components/index.ts barrel or from another directory in this same list. Not a live bug — components/ui/use-toast is already a documented shim onto the canonical store — but it is the main source of the oversized files, and the cluster is deletable once its barrel entries are pruned.

Telemetry egress exists but is off

backend/services/telemetry.py can POST to telemetry.otoyin.app, defaulting to enabled: false. enable_telemetry() is never called at startup.

Global theme pattern

One line-in-motion tile for all 7 themes, painted through a CSS mask so background-color carries each theme's own accent. Opacity 0.055, pointer-events:none. Verified by pixel-diff in every theme — computed style alone had hidden a transparent-light bug.
